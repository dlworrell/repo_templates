# Contributing

Thank you for contributing to `repo_templates`.

This repository defines the starting structure for future projects, so changes should be conservative, documented, and broadly useful.

## Contribution Rules

- Keep templates portable.
- Prefer plain text and Markdown for documentation.
- Avoid project-specific assumptions in shared files.
- Use placeholder tokens for values that vary by project.
- Document every non-obvious convention.
- Do not add dependencies unless they are justified by a clear benefit.

## Template Changes

When changing a template, update the relevant documentation and add a changelog entry.

Each template should remain usable without private infrastructure.
