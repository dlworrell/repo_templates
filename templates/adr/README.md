# ADR templates

`ADR-0000-catylist-code-of-conduct.md` is the standard ring 0 adoption record
from Catylist [ADR-0000](https://github.com/dlworrell/Catylist/blob/main/docs/adr/ADR-0000-catylist-code-of-conduct.md).
Copy it into the repository's ADR log (`docs/adr/` unless the repository
already keeps its ADRs elsewhere), fill `ADOPTED_DATE` and the Catylist commit
`CATYLIST_REVISION` the links are pinned to, and change nothing else.

If the log already has a record numbered `ADR-0000`, that record moves down to
the next free number and every reference to it is updated in the same pull
request (Catylist ADR-0000, section 3).
